## 一、总览：方法论步骤 ↔ 模块入口

| 霍尔逻辑维步骤 | 本研究活动 | 代码入口 |
| --- | --- | --- |
| ① 明确问题 | 界定学习成效、系统边界、CATWOE 根定义 | 报告 1.1—1.2（概念层）；系统边界图 fig01 |
| ② 选择目标 | 三层目标树（平台/教师/学习者）与冲突协调 | 报告 4.1（概念层） |
| ③ 系统综合 | 因素递阶结构（ISM 概念图）+ 画像×干预候选方案 | 报告 4.2；`up_decide.py` 干预候选构造 |
| ④ 系统分析 | 六源融合、统一聚类画像、序列/关联挖掘、多形态与内容级画像 | `up_build_unified.py`、`up_cluster.py`、`up_mine.py`、`multimodal.py`、`profile_modeling.py` |
| ⑤ 方案优化 | 无泄漏预测 + 早期预警 + AHP 模糊评价 + SD 仿真 | `up_predict.py`、`up_evaluate.py`（委托 `evaluators.py`） |
| ⑥ 作出决策 | 分层干预队列 + 0-1 预算规划 | `up_decide.py`、`multimodal.py::decide()` |
| ⑦ 付诸实施 | 一键复现、看板验证、再评价闭环 | `run_all.py` + 三个 `build_*.py` 看板构建 |

> 一键复现整条链：`run_all.py`（`--check` 体检 / `--device gpu` 显存加速）。它按依赖顺序调用：
> `multimodal → profile_modeling → up_build_unified → up_cluster → up_mine → up_associate →
> up_predict → up_evaluate → up_decide → up_report → 三个看板`。
> **方法出处口径**：系统评价以课堂讲授的 AHP 层次分析法为主体；熵权客观修正、TOPSIS 贴近度、
> 梯形隶属度模糊综合评价为自主拓展方法，答辩不得称其为课堂所讲。GM(1,1)、迁移测评、SD 仿真同属拓展。

### 7. 系统评价：AHP + 模糊综合 + SD 仿真（报告第 7 章）

| 编号 | 公式 | 代码位置 |
| --- | --- | --- |
| E1 | AHP 特征根法 `Aw = λmax·w`，归一化得权重 | `evaluators.py::ahp()`（唯一实现，`up_evaluate.py` 委托调用） |
| E2 | 一致性 `CI=(λmax−n)/(n−1)`，`CR=CI/RI[n]` | `evaluators.py::ahp()` |
| E3 | 模糊综合评判：隶属度矩阵 × 权重向量 → 百分制质量分 + 优/良/中/差分层 | `up_stages.py::ahp_fuzzy_scores()` |
| E4 | SD 系统动力学：三条反馈回路，欧拉法离散积分模拟 52 周 | `up_stages.py::sd_simulation()` |

**答辩要点**：AHP 权重 学习效果 0.558 / 学习行为 0.320 / 互动参与 0.122，CR=0.016<0.1 通过检验；
质量分均值 45.5 分（差 56,693 / 良 5,325 / 中 4,235 / 优 391）；
SD 最优策略"加强资源供给"（52 周 +233.3%）vs"加强平台激励"（−24.7%）。

### 8. 系统决策：干预队列与 0-1 规划（报告第 8 章）

| 编号 | 公式 / 约束 | 代码位置 |
| --- | --- | --- |
| O1 | 干预队列规则：预测风险 × 质量分层 × 画像类型 → 持续观察/拓展培养/教师复核/重点支持 | `up_decide.py` |
| O2 | 干预弹性倒 U 型 `Δ=3+56r(1−r)`；成本 `c=6+12(1−r)` | `multimodal.py::make_segments()` |
| O3 | 决策变量 `xⱼ ∈ {0,1}`；预期增益 `gainⱼ = n_s · Δⱼ` | `multimodal.py::decide()` |
| O4 | **目标** `max Σⱼ gainⱼ·xⱼ`；**约束** 预算 `Σcⱼxⱼ ≤ B`、同单元互斥 `Σ_{j∈s}xⱼ ≤ 1` | `multimodal.py::decide()` 中 `milp`（HiGHS） |
| O5 | 对照方案：经验法 / 普惠法 | `multimodal.py::decide()` |

**答辩要点**：多形态层预算 199,183 元（全量成本 442,629 元的 45%），最优组合预期新增高成效
1,373 人，较经验法 +173.6%、较普惠法 +81.8%；增益为既定弹性假设下的相对比较。
主线逐人干预队列 4 类覆盖全部 66,644 人（持续观察 45,292 / 拓展培养 11,980 / 教师复核 6,468 / 重点支持 2,904）。

### 9. 多形态建模与跨平台测评（`multimodal.py`，支撑报告 5.4、8.2）

| 编号 | 公式 / 规则 / 约束 | 代码位置 | 说明 |
| --- | --- | --- | --- |
| X1 | 四形态准备：MOOC 三平台对齐 / 微课聚合 / 短视频筛选 / 课堂对照 | `prepare_mooc()` / `prepare_micro()` / `prepare_shortvideo()` / `prepare_classroom()` | 平台内 z-score，缺失置 NA 不填 0 |
| X2 | 五维同构映射 `engage/persist/complete/interact/context` | `prepare_*()` | 形态内标准化，跨形态只比标准化值 |
| X3 | 教育类筛选 `root_id ∈ {14,29,38,21}`（窄口径 `{14}`） | `prepare_shortvideo(broad=True/False)` | 泛知识类占全量 2.19% |
| X4 | 时间切分：前 5 日特征 → 后 2 日回访标签 | `prepare_shortvideo()` | 防结果泄漏 |
| X5 | PSI `Σ(pᵢ−qᵢ)·ln(pᵢ/qᵢ)`；W1 Wasserstein；KS 检验 | `distribution_shift()` | PSI 微课 0.95 / 短视频 3.69 / 课堂 5.85，全部显著偏移 |
| X6 | 迁移测评：6 组"训练形态 → 测试形态" vs 域内 5 折 CV | `transfer_test()` | 域内均值 0.697 vs 迁移 0.657 |
| X7 | 形态效应：无形态项 vs 含形态虚拟变量，似然比检验 | `form_effect()` | 0.8078→0.9076（Δ=0.0998，LR=1772.6，p<0.001） |
| X8 | 平台效应：混合 AUC vs 平台内加权 AUC | `platform_effect()` | 通胀 −0.0171，支持按平台分层建模 |
| X9 | Bootstrap 120 次 95% CI + 替代标签对照 | `robustness()` | 区间不重叠，形态差异稳定 |
| X10 | AHP-熵权 + TOPSIS（5 准则，CR=0.00739） | `ahp()` / `entropy_weight()` / `evaluate()` | 评价单元为形态×平台 6 群体 |

**答辩要点**：核心不是"再算一遍 AUC"，而是用真实数据检验主线结论的**形态适用性**；
最易被追问的三处：① 短视频标签为什么是回访而非完课率（只有 7 天、无学业结果）；
② 微课 AUC 0.5369 不是模型失败（观看解释投入、不解释掌握）；③ 课堂对照无在线行为，
不进迁移矩阵、不参与干预预算。

### 10. 内容级画像（`profile_modeling.py`，支撑报告 5.5）

| 维度 | 方法 / 公式 | 代码位置 | 结果字段 |
| --- | --- | --- | --- |
| 观看时段偏好 | 小时级 `p_hour` → 用户主观看时段聚合占比 | `dimension_time_of_day()` | `time_of_day` |
| 兴趣爱好 | 类目观看占比向量、归一化类目熵、知识/娱乐偏好分位分型 | `dimension_interest()` | `interest` |
| 短视频用户属性 | 城市等级/性别/年龄/时段/城乡分组 × 完成度(`watch/duration` 截断 1)；Kruskal–Wallis H | `dimension_sv_profile()` | `sv_profile` |
| 天池倍速与终端标签 | 倍速/设备/OS/网络/预习分组 × 进度增益；**严格限定 video_play 事件**避免 1.0× 默认伪影；KW H + Mann–Whitney U | `dimension_tianchi()` | `tianchi` |

**答辩要点**：四个维度均由国内真实数据实算（短视频 6,654 用户、天池 715 学习者），不含仿真；
时段峰值晚间 32.6%、均衡杂食型 63.3%、知识求知型仅 6.7%；
倍速与预习在排除伪影后差异不显著，提示不可把习惯性操作误读为成效因果。
"兴趣""完成度"均为代理口径，伦理边界见报告 5.5 与看板底部。
