### 2.1 派生规则（全部来自真实字段，无随机生成）

1. **人口属性**：直接取 `studentInfo` 的 gender / region / highest_education / age_band /
   num_of_prev_attempts；地区与学历译为中文，年龄取区间中值。
2. **访问次数** `visit_count`：该学习者在课程内 `studentVle.sum_click` 的累计求和（真实点击）。
3. **活跃天数** `active_days`：该学习者出现过的不同 `date` 天数（真实）。
4. **论坛互动** `forum_posts`：`vle.activity_type = forumng` 类资源的点击数（真实互动代理）。
5. **首次参与滞后** `first_active_lag`：最早出现的 `date`（真实，0 表示开课即参与）。
6. **资源覆盖度** `video_rate`：访问过的 `oucontent` 资源数 / 该课程 `oucontent` 资源总数（代理）。
7. **作业提交率** `assign_rate`：有得分的 TMA/CMA 数 / 应提交 TMA/CMA 数（真实提交记录）。
8. **测验均分** `quiz_avg`：TMA/CMA 得分均值（真实，0—100）。
9. **期末成绩** `final_grade`：按测评权重加权的真实得分（0—100）。
10. **前期行为**（预测专用，先于结果发生）：第 2 / 4 周累计点击与活跃天数 `early_w*`。

> 诚实性声明：OULAD 不直接记录"学习时长"与"视频完播"。本表把
> `study_hours = 累计点击 × 0.10 分钟/次 ÷ 60`、`avg_session_min = 累计点击 × 0.10 ÷ 活跃天数`
> 作为**等效投入代理指标**，仅用于横向比较，不代表真实计时，报告第 3.4 节与正文表格均已标注。

### 2.4 无泄漏预测口径（重要）

标签 `certificate` 是学期末真实结果；`quiz_avg`、`final_grade`、`assign_rate` 与结果同期同生，
若入模等于"用结果预测结果"。因此 `analysis.py` 定义独立的 `PREDICT_FEATURES`，
**只含第 4 周之前的行为**（前 2/4 周点击与活跃、累计访问/活跃/论坛/资源覆盖、首次滞后）
**与人口属性**（年龄、既往重修次数）。前期行为与结果相关系数约 0.22—0.25，属合理可预测范围。

### 2.5 可复现方式

```bash
cd "选题7_最终交付/03_源代码"

# 1) 从 OULAD 原始表派生真实主表（需原始 OULAD 目录；派生后的 csv 已随包交付）
python build_real_learners.py --oulad-dir <OULAD原始目录> --out-dir ../02_数据与数据集

# 2) 重新运行全部模型，得到报告基准结果（用随包真实主表，无需原始数据）
python app.py --batch --k 4 --budget 0.45 --seed 20260101 --out ../04_运行结果/results.json

# 3) 重新生成报告插图
python figures.py

# 4) 重跑多形态建模与测评
python multimodal.py && python multimodal_figures.py
python forecast.py && python fuzzy_eval.py && python demo_runs.py

# 5) 重新生成单文件看板与报告
python ../05_图表与看板/build_dashboard.py
python ../01_研究报告/build_final_report.py
```

`app.py --batch` 输出的多形态/主线字段与交付的 `04_运行结果/results.json` 逐项一致；
`04_运行结果/multimodal_results.json` 是国内多形态层数字的唯一来源。

## 三、六源多形态真实数据的外部实证检验

选题指南要求"尽可能收集不同线上平台的学习者数据"，且研究对象须覆盖 MOOC、微课、短视频。
国内内容级证据链已实际下载、核验并建模 6 个公开数据源：

| 形态 | 数据集 / 平台 | 实测规模 | 用途 |
| --- | --- | --- | --- |
| MOOC | HMXPC13（edX HarvardX/MITx） | 641,138 行 ×20 列、16 门课 | 三平台对齐样本主源 |
| MOOC | OULAD（英国开放大学 VLE） | 32,593 条选课、7 张表 | 三平台对齐样本主源，亦为第二节主表来源 |
| MOOC | KDD Cup 2015 / XuetangX（学堂在线） | 39 门课、2,171,850 行 | 三平台对齐样本主源 |
| 微课 | 中国高校慕课课程多维画像与学习行为脱敏样本（阿里云天池） | 5,000 条事件 ×22 字段、4,655 个微资源 | 章节级微资源会话 |
| 短视频 | 清华 FIB 实验室 WWW 2025 短视频行为数据集 | 采样版 794,053 行 ×28 字段、6,654 用户、7 日窗口 | 泛知识类筛选 + 时间切分建模 |
| 课堂对照 | UCI #320 Student Performance | 1,044 行 ×33 字段 | 零在线对照端点 |

四份随包建模样本共 **9,236 条**（MOOC 6,000 / 微课 723 / 短视频 1,469 / 课堂对照 1,044），
全部数字由 `multimodal.py` 实跑，汇总于 `04_运行结果/multimodal_results.json`。

**边界说明（必须如实披露）**：

- 三平台量纲与缺失结构不同，先平台内标准化再进入统一五维框架，**未直接合并原始计数**；
- 四类标签语义不同（认证 / 测验通过 / 后 2 日回访 / 期末成绩），只作"同构代理"，
  **不得混称完课率或达标率**；迁移测评衡量关联结构可迁移性，不等于可部署的跨域预测性能；
- 短视频为 7 天采样版、教育类需自行按一级类目筛选（占全量 2.19%），
  且采用"前 5 日特征 → 后 2 日标签"的时间切分以杜绝结果泄漏；
- UCI #320 是传统课堂问卷数据，**不是微课、不含在线行为**，仅作零在线对照，
  且**不参与第 8 章的干预资源分配**；
- 大体量原始文件（约 970 MB）不随交付包分发，但随包样本已足够离线复现国内多形态层每个数字；
  获取地址、许可、类目筛选规则、字段字典与复现命令见《多形态数据说明.md》。

### 3.1 六维画像所用字段（报告 5.2）

六维画像由 `profile_modeling.py` 实算，结果写入 `profile_results.json`，全部为真实字段：

| 画像维度 | 数据来源 | 使用字段 | 代理口径说明 |
| --- | --- | --- | --- |
| 地区差异 | OULAD 主表（英国） | `region`（13 类） | 英国地域分类 locale，非国籍，不外推 |
| 专业背景 | OULAD 主表 | `education`（5 类）、`discipline`（7 编码）、派生 `course_num` | 无"专业"自陈字段，以学历+课程模块+选课门数代理 |
| 学习习惯 | OULAD 主表 + 短视频原始 | `first_active_lag`/`active_days`/`avg_session_min`/`video_rate`；短视频 `p_hour`/`watch_time` | 行为节律代理；OULAD 日粒度与短视频小时级分层呈现不合并 |
| 兴趣爱好 | 短视频原始 sampled（中国） | `root_id`→38 个一级类目、`watch_time`、互动字段 | 内容观看占比推断的行为偏好，非心理测量 |
| 短视频用户属性 | 短视频原始 sampled（中国） | `fre_city_level`/`fre_city`/`fre_community_type`/`gender`/`age`/`p_hour`/互动字段 | 国内 365 城市 + 城市等级；完成度为观看时长/视频时长截断 1 的代理，非真实完课 |
| 天池倍速与终端标签 | 天池脱敏微课（中国） | `playback_speed`/`device_type`/`client_os`/`network_type`/`remark`(预习)/`assessment_tag`/`progress_before_pct`/`progress_after_pct` | 倍速与预习对照严格限定 `video_play` 事件（2,614 条），因原始数据把非视频事件倍速统一记为 1.0× 会造成伪影 |

**地域来源**：画像同时包含**国内数据**（短视频 365 座中国城市 + 城市等级、天池国内脱敏微课）与英国 OULAD 13 大区，
二者在报告与看板中分层呈现、不合并、不互推。

短视频/天池原始 sampled 数据（短视频 794,053 行 ×28 字段；天池 5,000 行 ×22 字段）
位于工作区 `../选题7_学习者行为分析/data/multimodal/raw/`，因体量较大不随交付包分发。
为让交付包离线可复现，`build_profile_inputs.py` 已从原始数据派生三张细粒度输入表随包交付：
`shortvideo_profile.csv`（6,654 用户）、`tianchi_profile.csv`（5,000 事件）、`shortvideo_cat_watch.csv`（37 类目）；
类目中文名映射取自 `categories_cn_en.csv`。`profile_results.json` 与六维画像看板已随包交付，
**仅查看报告与看板、或重跑 `profile_modeling.py` 均无需原始数据**；仅当需重新派生输入表时才需要。
